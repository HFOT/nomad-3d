# NOX — Proof Bearer (09)

黒漆の仮面をつけた、浮遊するからくり。Midnight（プライバシー）を担う9体目。

下半身はなく、幾重にも重なるリングがエネルギーの核を包んで回る。
リングは時おり開いては閉じ、核の光が見え隠れする。
消さない。ただ、見せ方を選ぶだけ — selective disclosure の体現。

## 操作

- しぐさ: 待機（その場で漂う）/ 漂う（フィールド巡回）
- 見せずに、証す: リングが開き、足元から証明の印（シジルリング）が浮かんで消える
- 写真を撮る / モデルを保存 (GLB) / 一時停止 / 自動回転

## ファイル

- `model.js` — 手続き型モデル。`buildNox()` が root / rig / clips / tick を返す
- `viewer.js` — シーン・パネル配線・証明の印。`window.nox.step()` は手動1フレーム実行（デバッグ用）
- `index.html` / `style.css` — ページ。夜藍のパレット（アクセント #939bf0）
- `preview.png` — ハブカード用 1600×1100 レンダー
