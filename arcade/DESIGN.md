# からくり遊技館 — 構造と再現範囲

Creator: CORN. Local preview: `/arcade/`. Reference: `concept.png`.

## 画像から採用した要素

- 大金庫と同じ黄灰色の石造。実装も `vault/materials.js` の `stoneMaterial()` を共有する。
- 下階の横長の大アーチ／上階の半円形の機械室／両脇の八角灯塔。
- 黒鉄の骨格、真鍮の歯車・装飾、紺色の歯車旗、暖色の炎。
- 左の螺旋球レール・中央の3連リール・右の円筒クレーン。
- 地上を空けた可視配管、フランジ、圧力調整筒、街の主配管へ向く左右の接続。

単眼のコンセプト画像からの寸法付き再構成であり、写真測量・画素単位の一致ではない。背景の大金庫・運河・他の街区は今回の独立モデルに含めない。

## 補完した内部

画像では不明な奥行きと背面を、整備可能な配置として設計した。背面作業台には引き出し、工具、予備歯車、圧力計、分岐弁。2折れ36段の階段、踊り場、側面と背面の点検回廊、柱・トラス・ボルト接合部を持つ。中央は吹抜けで、上階全面の床で歯車を隠さない。

大アーチと側面・背面窓は実際の開口。壁の石積みも開口を避けて切り分ける。外壁・屋根は表示切替可能。背面整備室の視点では背面壁も外す。

### 3つの独立した装置

1. **螺旋装置**：2本の立体レール、レール支持腕、5個の移動球、縦の搬送ラック、6個の昇降バケット、回収シュート、操作盤。
2. **リール装置**：3本の独立ドラム、各10個の立体記号、軸、側面歯車、背面歯車とばね、操作レバー、ボタン、受け皿。
3. **クレーン**：円筒ガラス、柱、台車レール、横移動台車、巻上げドラム、伸縮ワイヤー、4本の関節付きの爪、18個の景品、操作盤。

## 動力と配管

上階の主歯車は80歯、共通モジュール0.0625 m、基準圧力角20度。24歯・14歯の従動歯車はピッチ円の半径和で配置し、逆方向・歯数比の速度で動く。主軸、軸受、背面の伝達プーリー、天井の横軸、各装置への垂直継手を配置。

回転・球・クレーンは時間関数による**運動デモ**。接触力学、歯面強度、完全な動力伝達、球の衝突や受け渡し、景品の把持を解く物理シミュレーションではない。回路は視覚上の接続であり実設備設計ではない。GLBの24秒クリップを任意ループすると、一部の従動部・球が折り返す。ブラウザの連続時間デモでは24秒の切り替えはない。

標準接続は既存住宅と同じ `flame-DN440`、半径0.22 m、上向き。ローカル座標 `[-11,9,3.4]` / `[11,9,3.4]`。敷地メタデータ27×23 m、最大高さ16.6 m。`planNetwork` に必要な `root/ports/maxHeight` を返し、移動2通り×回転4通りで金庫の仮想接続点まで到達できることをテストする。

## 町への設置

`town/landmarks.js` の `createArcade` が原寸のまま `(-73, 16)` に建てる。正面は六角環状路に向く。街路網が唯一この規模を残していた西側の街区で、外周の連絡道と西の放射道路がその三方を囲む。敷地は `LOTS` に登録してあり、行き止まりの街路はこの敷地の手前で止まる。

2つの接続口は住宅街の空中配管（`town/residence-quarter.js` の `guests`）に合流し、他の家と同じ幹線で大金庫まで届く。専用の供給線は持たない。町の主配管高さは遊技館の16.6 mに合わせて上がる。

## 配布と検証

- `world/arcade/CORN-arcade-building.glb`：建物全体、石材テクスチャ、アニメーション。
- `world/arcade/CORN-arcade-machine-{1,2,3}.glb`：各装置。原点に置き直し、関連する動作トラックのみ収録。
- `world/arcade/manifest.json`：サイズ、検証結果、接続口。
- `node tests/arcade-kit.mjs`：構造／可動／接続／GLB検証と書き出し。
- `node tests/arcade-render.cjs`：8視点＋モバイルの実ブラウザ画像。
- `npm run check` / `npm run build`：既存サイトを含む構文と静的ビルド。

GLBの石材バンプは `EXT_materials_bump` を使用するため、未対応ビューアでは微細な凹凸が省略される。基本色テクスチャと石積み形状は残る。公開・pushは未実施。
