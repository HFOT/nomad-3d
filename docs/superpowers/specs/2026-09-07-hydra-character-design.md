## コンセプト

Hydra（CardanoのLayer 2スケーリングプロトコル）を担う10体目のからくり。
シリーズの「灯りを運ぶ」テーマの中で、HYDRAは
**「五つの炎で速さを生み、一発に束ねてLayer 1へ返す者」**。
オフチェーンで高速処理し、結果だけをメインチェーンに決済するという
Hydra Headの思想（open head → off-chain txs → settle to L1）を体現する。

※番号について: 8体目は別マシンで制作中、9体目はNOX（Midnight担当）。
HYDRAは **10** として実装する。

## 姿（モデル仕様 — `hydra/model.js`）

手続き型Three.jsモデル（既存キャラと同方式、外部アセットなし）。

- **体**: 漆黒のからくり装甲 + 白磁の頭（シリーズ共通文法）。
  黒ボディはシリーズ初。マットな黒鉄にアクセントの赤が映える。
- **背中のハブ + 5本アーム**: 真鍮のハブから5本の可動アームが放射状に伸び、
  先端にそれぞれ**特殊ランタン**を保持。5つのランタン = 5つのHydra Head。
- **特殊ランタン（×5）**: ガラスの中で**赤い炎が高速回転**し続ける。
  らせん状のリボン+コアで炎を構成し、残光の輪を描く。
  Idle中も回転は止まらない — 「静止していても常に何かが回っている」が
  シリーズ内での差別化点（他キャラのランタンは静かに灯る）。
- **銃（からくり式ライトキャノン）**: 片手に真鍮+黒鉄の銃。
  5つのランタンから**赤い光の筋が銃に流れ込み、チャンバーに光弾が充填**される。
- **アニメーションクリップ**:
  - `Idle` — 呼吸のような胴体の揺れ、アームの微揺れ、炎の常時回転
  - `Walk` — その場歩行。股・膝・腕の連動、アームが慣性で揺れる

## メイン機構: 「L1へ、返す」（L1決済の比喩）

パネルの特別アクション **「L1へ、返す」** ボタン:

1. 5つの炎の回転が一斉に加速する
2. 各ランタンから光の筋が銃へ収束し、チャンバーが眩しく満ちる
3. **発射** — 赤い光弾が尾を引いて飛び、遠くで静かに弾ける（=L1決済）
4. 発射後、炎の回転は通常速度に戻る
5. status表示「決済完了 · n shots」でカウント
   （PIPの「配送完了 · n packets」、NOXの「証明完了 · n proofs」と対になる）
