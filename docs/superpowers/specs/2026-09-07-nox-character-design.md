## コンセプト

Midnight（Cardanoのプライバシーチェーン）を担う9体目のからくり。
シリーズの「灯りを運ぶ」テーマの中で、NOXは灯りを消す者ではなく
**「灯りを覆い、見せ方を選ぶ者」**。プライバシー＝隠蔽ではなく選択、
というMidnightの思想（selective disclosure / ZK証明）を体現する。

※番号について: 8体目は別マシンで制作中（役割はNOXと被らない）。
NOXは **09** として実装する。

## 姿（モデル仕様 — `nox/model.js`）

手続き型Three.jsモデル（既存キャラと同方式、外部アセットなし）。

- **浮遊体**: 足を持たない。マントの裾は宙に溶けるように閉じ、
  地面から浮いて上下にゆっくり揺れる（ホバリング）。
- **フード + マント**: 宵闇色（マットな夜青）。Lathe/Cone系ジオメトリで
  布の垂れを表現。ドリフト時は慣性でなびく。
- **仮面**: フードの奥に白磁の仮面。能面のような無表情のマスクで、
  細い目のスリットだけが淡く光る（emissive）。仮面の下は見えない。
  ミステリアスさの核。
- **シャッター付き提灯**: 片手に覆い付きの提灯。覆いのスリットから
  琥珀の光が漏れる。シリーズの灯りテーマの継承点。
- **アニメーションクリップ**:
  - `Idle` — その場で漂う。上下の揺らぎ、マントの微細な波、提灯の灯りの明滅
  - `Drift` — フィールドをすーっと滑るように巡る。マントと提灯が後方になびく

## メイン機構: 証明の印（ZK証明の比喩）

パネルの特別アクション **「見せずに、証す」** ボタン:

1. 提灯は閉じたまま（開かない — ここが思想の核）
2. 足元にリング状のシジル（証明の印、アクセント色の発光リング＋紋様）が
   浮かび上がり、ゆっくり上昇して消える
3. status表示「証明完了 · n proofs」でカウント
   （PIPの「配送完了 · n packets」と対になる）

## 改訂 2026-09-07（実装中のCORN指示による設計変更）

布のマント案は「粗く見える」ため廃止。最終形は以下:

- **他キャラと同じからくり構造**: 漆塗り（夜藍ラッカー）の胴 + 真鍮の継ぎ目 +
  関節式の腕 + 白磁の手、というシリーズ共通の造形言語
- **黒漆の仮面**: 白磁の頭部を覆う黒いクリアコートの仮面。真鍮の縁取り、
  細い藍の目スリットのみ発光
- **下半身なし・浮遊**: 球体のエネルギー核を、幾重にも重なるリング（4本、
  交互に真鍮/黒鉄、縁が発光）が包んで回転し、浮遊する
- **提灯は廃止**: 「見せ方を選ぶ」ギミックはリングが引き継ぐ。リングは
  ゆっくりした周期で開閉し、閉じている間は核の光が殻に隠れ、開くと
  光があふれる。「見せずに、証す」実行中は強制的に開く
- 証明の印（シジルリング上昇）・しぐさ（待機/漂う）・コピー・色は当初案のまま
- 途中経過として実装した「フード+マント+シャッター提灯」版は
  gitログ（3fd586f以前）に残っている

なお8体目とは別に、このリポジトリでは並行して HYDRA (10) が制作中。
