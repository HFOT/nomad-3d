PIP TYPE

寄ってくる滞留の頭上に、Cardanoの語が浮かんでいる。打ち切った語が、そのまま投擲になる。

  • 手は打つだけ ‥ 移動もボタンもありません。語をタイプすると、PIPが投げて捌きます
  • 最初の一字で決まる ‥ その字で始まる一番近い相手にロック。打ち切るまで変わりません
  • 打ち間違いは進まないだけ ‥ ミスは数えられ、正確さとして最後に出ます
  • 速いのは短く、遅いのは長い ‥ 割れるやつは、割れてから二語になります
  • 60秒を打ち切るとブロックが刻まれ、力尽きると空のブロックになります
